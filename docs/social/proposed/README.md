# Proposed social copy — awaiting approval

The weekly content-producer routine drafts candidate social copy here from
`stage:curated` content-queue issues. Each file carries a `Queue-Issue: #NNN`
header pointing back to the source issue.

To approve: `git mv docs/social/proposed/<file> docs/social/backlog/` and push.
The daily autopilot queues from `backlog/` automatically.

To reject: delete the file (and optionally close or relabel the queue issue).
