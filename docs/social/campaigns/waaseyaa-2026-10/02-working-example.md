## Bluesky

One content model, more than one interface. Waaseyaa.org serves its published content as HTML, Markdown and read-only MCP. The website is itself a Waaseyaa application. Explore how it works: https://waaseyaa.org/build

## LinkedIn

An application’s content can be useful through more than its web interface.

Waaseyaa.org is a working example. The site runs on Waaseyaa and makes its published content available as HTML, Markdown and read-only MCP.

That gives developers and agents different ways to read the same material. The site’s access policy blocks runtime writes.

Framework is alpha. If you’re evaluating it for a content application, start with the learning path: https://waaseyaa.org/build

## Facebook

Waaseyaa.org runs on the framework it documents.

Its published content is available as web pages, Markdown and read-only MCP. That makes the site a concrete example to inspect when we talk about content being useful to people and agents.

I’m building out the learning path around that idea. If you work on content applications, explore it here: https://waaseyaa.org/build
